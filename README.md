# Yue Fan — Academic Website

A lightweight, responsive academic website prepared for faculty-job applications and GitHub Pages.

## Publish with GitHub Pages

1. On GitHub, create a **public** repository named exactly `Yuegkg.github.io`.
2. Upload the contents of this folder to the repository root (not the enclosing folder itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose the default branch (normally `main`) and `/ (root)`, then save.
5. The site URL is `https://yuegkg.github.io/` once the Pages deployment is successful.

## Files

- `index.html` — one-page academic site
- `styles.css` — responsive visual design
- `assets/Yue_Fan_Academic_CV.pdf` — CV linked from the site
- `assets/favicon.svg` — browser icon
- `404.html` — fallback page
- `robots.txt` and `sitemap.xml` — basic search-engine discoverability
- `.nojekyll` — tells GitHub Pages to serve the static files directly
